Header: informações adicionais sobre a comunicação.
Body: dados/conteúdo da mensagem.
Content-Type: informa o formato dos dados enviados.
Accept: informa o formato que o cliente quer receber.
Authorization: envia credenciais/token.
Authentication: verifica quem é o usuário.
Authorization: verifica o que o usuário pode fazer.
Token: credencial usada para autenticação.
401: falha na autenticação.
403: autenticado, mas sem permissão.
404: recurso não encontrado.
500: erro interno do servidor.
Agente: envia Request → recebe Response → interpreta → responde ao usuário
